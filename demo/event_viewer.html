Open a capture from sensors — every run writes one to captures/sensors-*.jsonl — or drop it anywhere on this page, or paste the JSON lines below. Each kernel event becomes a plain sentence; background churn is suppressed by named rules you can switch off; and what survives is grouped by process lineage so a multi-step chain reads as one story.

Noise filters

Suppression never hides a finding. Credential reads, anything run from or written to a temp directory, and connections to unusual ports stay visible no matter which rules are on — including when they match a rule's own pattern. Noise rules only ever remove events that scored nothing.

EXEC — process launched FILE — opened for write, or a watchlisted secret read NET — outbound TCP connect

The column is relative to the first event in the paste because that is the easier thing to read; each record also carries an absolute ts (epoch nanoseconds) and time, which the loader derives from the kernel's boot-relative clock at capture.

parent unknown now means genuinely unknown — the loader backfills the parent from /proc for processes that predate the capture, so only a process that also exited before it could be read stays unattributed. Source ports read 0 on outbound connects: at the SYN_SENT transition the ephemeral port is not assigned yet.
